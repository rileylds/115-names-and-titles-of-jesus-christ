# 耶穌基督的115個名稱與頭銜

依 Matthew Brooks〈115 Names and Titles of Jesus Christ〉（《利阿賀拿》數位專文）所列的 115 個名稱與頭銜，
逐條附上經文出處與**整節**中文經文，並將對應的名稱片語加粗。頁面內建搜尋，可用中文名稱、英文原名或經文出處篩選。

## 經文來源

- 教義和聖約、摩西書、摩爾門經、新約、創世記至出埃及記：churchofjesuschrist.org 中文經文（`lang=zho`），出處連結直達該節。
- 以賽亞書、耶利米書、以西結書、撒迦利亞書、瑪拉基書：該站無中文經文，中文採**和合本**（1919，公有領域），
  文字取自 BibleGateway CUV，出處連結為 BibleGateway 的和合本／英王欽定本（CUV；KJV）對照單節頁。

## 使用

`index.html` 是完整的單機檔案，所有樣式與程式都在檔內，直接開啟即可，也可放在任何靜態主機上。
