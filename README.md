# 耶穌基督的名稱與頭銜

兩份中英對照的經文研讀清單，逐條附上經文出處與**整節**經文，並將對應的名稱片語加粗。
頁面內建搜尋，可用中文名稱、英文原名或經文出處篩選；預設中英對照，可切換為純中文或純英文。

## 兩個頁面

| | 網址 | 內容 |
|---|---|---|
| **基礎** | [首頁](https://rileylds.github.io/115-names-and-titles-of-jesus-christ/) | 耶穌基督的 50 個名稱與頭銜（ComeUntoChrist.org） |
| **進階** | [115-names.html](https://rileylds.github.io/115-names-and-titles-of-jesus-christ/115-names.html) | 耶穌基督的 115 個名稱與頭銜（《利阿賀拿》，Matthew Brooks） |

建議先讀 50 條那份，再進到 115 條。兩個頁面互相有連結。

研讀時，為每一個名稱問自己兩個問題：

1. 這個名稱和頭銜是什麼意思？（點擊名稱即可開啟經文指南的定義）
2. 這個名稱和頭銜教導我，為什麼我需要與耶穌基督建立關係？
